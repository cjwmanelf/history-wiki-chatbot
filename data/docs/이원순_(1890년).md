# 이원순 (1890년)

분류: 1890년 출생, 1993년 사망, 고려대학교 교수, 고려대학교 동문, 대한민국 임시정부 사람, 대한민국의 감리교도, 대한민국의 기업인, 대한민국의 독립유공자, 대한민국의 반공주의자, 대한민국의 백세인, 대한민국의 별정직공무원, 대한민국의 사회 운동가, 대한민국의 정치인의 배우자, 신민당, 연세대학교 교수, 일제강점기의 사회운동가, 자유당, 조선의 사회 운동가, 한국계 미국인, 한국독립당의 당원, 한국의 독립운동가

이원순(李元淳, 1890년 10월 8일 ~ 1993년 4월 19일)은 한때 미국 영구거주권을 취득한 전력이 있는 대한민국의 독립운동가, 기업가, 정치인, 사회기관단체인이다. 본관은 연안(延安)이며 호는 해사(海史). 한성부 출생이다.
1914년 경성 보성전문학교 전문학사 학위 취득과 동시에 미국으로 망명, 이승만의 측근으로 활동하며 독립운동에 종사하였다. 1993년에 별세하였는데 향년 104세였다.
